# Contributing

Run `npm test`. Add a test for changed adapter or fingerprint behavior. Keep
the module free of runtime dependencies and keep user input local unless a
caller explicitly chooses an external adapter.

Credit work with a named observation or source. An unknown influence may remain
unknown. Do not turn a transport acknowledgement into proof of sensation or an
authorship assertion into a verified identity. Record which runtime and version
you exercised. Keep existing licenses with their own components.
