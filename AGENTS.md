# U Device

Keep `u.mjs` readable and dependency-free. Human labels are open; capability
claims need an adapter and a scoped observation. Never claim all devices,
all future time, sensed meaning or anonymity from software receipts.

Preserve the custom license and honest contributor record. Original Joy-Con
driver code lives in ChuuWork/ChuuMind with separate Apache credits; do not
relicense it into this module. Tests are `npm test` and the real browser Home
demo checks. Publish only reviewed files; private asks and device identities
never belong in the repository. Use Justichuu's public noreply commit identity.

Work from this repository. The retired `u-core` and `u-device` histories are
retained here; their folders are not separate products. The experimental
`retained/perennial` branch is preserved without becoming part of the active
product. Read the repository-history section in README.md before changing refs.
